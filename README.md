## How to use
1. Download v32.
2. Extract the zip.
3. Copy `DWrite.dll` into the game `bin` folder.
4. Launch BG3. Open the console if a mod asks.

## Key Features
- bg3se console
- Lua / Osiris
- Auto-update after Patch 8
- GitHub only (not Nexus reuploads)

## FAQ

**No new GitHub file after a game patch?**
The extender auto-updates. A new GitHub tag is the updater, not every SE bump.

**Red console text?**
Test with no mods. Notes in `files/notes/`.

## Requirements
Windows 10/11. Baldur's Gate 3 Patch 8.
